## Desarrollo local

Requisitos: Node.js `>=22.12.0`.

```bash
npm install
npm run dev
```

El sitio estará disponible en `http://localhost:4321`.

Para generar y revisar una versión de producción:

```bash
npm run build
npm run preview
```
